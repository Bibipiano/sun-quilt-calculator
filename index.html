    1. 太阳位置（Spencer / NOAA 简化式） 
    γ = 2π(N−1)/365                                   N = 一年中第几天
δ = 0.006918 − 0.399912cosγ + 0.070257sinγ − 0.006758cos2γ + 0.000907sin2γ − 0.002697cos3γ + 0.00148sin3γ     （赤纬，弧度）
EoT = 229.18×(0.000075 + 0.001868cosγ − 0.032077sinγ − 0.014615cos2γ − 0.040849sin2γ)                         （时差，分钟）
真太阳时 = 钟表时间 + 4×(经度 − 15×时区) + EoT        时角 ω = 15°×(真太阳时 − 12)
s = (E, N, U)：E = −cosδ·sinω,  N = sinδ·cosφ − cosδ·cosω·sinφ,  U = sinφ·sinδ + cosφ·cosδ·cosω
高度角 h = asin(U)，方位角 A = atan2(E, N)（正北顺时针）
    2. 日出、日落与海拔修正

    cosω₀ = (sin h₀ − sinφ·sinδ) / (cosφ·cosδ)，h₀ = −(0.833° + 0.0293·√海拔)。0.833° 为大气折射修正，海拔项为地平下沉（视野更开阔，日出更早、日落更晚）。纬度越高、冬夏差异越极端；若 cosω₀ 超出 [−1,1] 则出现极昼或极夜。

    3. 晾晒几何与受光面积

    被子按矩形处理（长 L × 宽 W），折叠厚度 t 压在绳上。折痕与绳平行，折点把“与绳垂直的那条边”分成 f 与 (1−f) 两段，因此两侧下垂高度为 f·D 与 (1−f)·D（D 为与绳垂直的边长）。

    两层被面互为阴影，某时刻朝向太阳的“剪影”由较长的一层决定（含下缘漏光近似），于是瞬时有效受光面积为：

    A(t) = S × [ Lmax × cos h(t) × |cos(A(t) − β)| + t × sin h(t) ]
S = 沿绳展开长度（长边沿绳时为 L，宽边沿绳时为 W）
Lmax = max(f, 1−f) × D        β = 绳向方位 ± 90°（两层被面法线）
第一项为两面被子的投影受光，第二项为绳顶折转面的受光
    4. 折叠决策（方案寻优）与安全约束

    工具把「沿绳边」与「折点分数」当作决策变量，在全部组合中搜索当日受光量最大的方案：

    方案 = （沿绳边 ∈ {长边, 宽边}）×（折点 = 较长一侧占比 f ∈ [0.5, 0.9]）
受光量 G(方案) = S × [ f × D × Icos + t × Isin ]      （S、D 随沿绳边切换）
约束① 摩擦：f/(1−f) ≤ κ/1.3     （κ=e^(μπ)，1.3 为安全系数，留余量）
约束② 离地：f × D ≤ 绳高 − 0.06 m（最低点离地不少于 6 cm）
约束③ 绳长：S + 0.2 m ≤ 可用绳长（含打结余量）
在满足全部约束的方案中取 G 最大者作为推荐

    一个值得注意的性质：在相同折点下，「长边搭绳」与「宽边搭绳」的两层受光总量几乎相同（因为 S × f × D 都等于 折点比例 × 被面积），差别只在顶部折转面的长度；两者真正的区别在于所需绳长与下垂深度限制。绳长足够、绳高较低时，长边搭绳往往更优（同样折点下垂更浅，允许更大的不对称度）；绳偏短时应选择宽边搭绳。

    为什么推荐折点几乎总是 66:34？受光面积正比于「较长一层」的下垂长度（两层互遮后由剪影决定），折得越不对称受光越多，所以最优折点总是顶在约束允许的最大值上——默认 μ=0.30、留 1.3× 安全余量时即为摩擦安全上限 66.4%。它不随地点、日期、绳向变化（太阳条件只决定「较长一侧朝哪边」和 G 的数值）；改变摩擦系数 μ、或把绳高降到离地约束先起作用的程度，推荐折点才会移动。

    朝向判定（上午/下午）：南北走向的晾绳，两侧受光在理论上完全对称（正南北时相差 0.0 分钟）；东西走向则差异极大（动辄数小时）。判定规则：两侧受光积分差小于 0.6 h（约合手机指南针误差与磁偏角的影响量级）时视为「两侧相当」，不给出强制朝向；0.6–1.5 h 之间按「略优」提示；更大差异才给明确结论。手机指南针读的是磁北，与真北可能相差数度，本规则对此已做钝化处理。

    5. 光照分数（面积 × 时间）

    G = ∫ A(t) dt（日出到日落，单位 m²·h）。它把“某一刻被照到多大面积”沿时间累加，即“总受光照面积时间”。界面上的分数 = 当前方案 G ÷ 当日通过改变绳向所能达到的最优 G* × 100。

    注意：分数按几何受光量（面积×时间的余弦加权）计算；能量估算（MJ）另行加权了直射光功率与低角度大气衰减，两者趋势一致但数值差异不同。

    6. 质量均匀假设与“会不会滑落”

    被子视为质量均匀分布：折点两侧重量比为 f : (1−f)。布面绕过晾绳的接触弧约 π，按卡普斯坦（capstan）摩擦模型，不滑落条件为：

    T₁/T₂ ≤ e^(μ·π)   →   f/(1−f) ≤ κ，κ = e^(μ·π)   →   折点上限 f ≤ κ/(1+κ)

    默认 μ = 0.30 时理论极限约 72:28；推荐折点另留 1.3× 安全余量（约 66:34）。实际使用中可在折痕压绳处缠防滑胶带或用晒衣夹，进一步降低滑落风险。

    7. 能量估算（大气质量与直射强度） 
    AM = 1 / [cos z + 0.50572·(96.07995 − z)^(−1.6364)] × (P/P₀)，z = 天顶角
P/P₀ = (1 − 2.25577×10⁻⁵ × 海拔)^5.25588
DNI = 1353 × 0.7^(AM^0.678) × kc      （W/m²，kc 为天气通透度）
Q = ∫ DNI(t) × A(t) dt                （焦耳级能量，按完全吸收估算）
    8. 关于经纬度、海拔与罗盘方位读数

    经纬度与海拔描述晾晒地点，决定太阳的轨迹（高度角、方位角、日出日落时刻、大气衰减），与被子的长边、宽边无关。

    罗盘方位读数（如 90°）描述的只是晾绳的走向。被子哪条边与绳平行、折点放在哪里，是“怎么晒”的决策，由本工具计算推荐（首屏结论），你也可以在侧栏固定某条边做对比。测量时手机水平、沿绳方向指向远端读取即可；指向相反方向读数相差 180°，等效。

    9. 假设与局限
    • 只统计太阳直射光。天空漫射光、地面反射、云层动态、湿度与风速未纳入，这些在阴天与低温环境下会显著影响实际干燥速度。
    • 被子被理想化为“刚性平面悬挂”，忽略织物的鼓包、下垂弧度与层间贴合变化；两层互遮按剪影（含下缘漏光）几何近似。
    • 无建筑、树木、阳台栏杆等遮挡；假定空旷且地面无反射。
    • 能量按完全吸收估算（未扣面料反射率），属量级参考。
    • 摩擦模型为均匀接触的理想化 capstan 近似，实际绳材与被套材质差异较大；风载未计入。
    • 结论适合比较不同晒法、时段与季节的相对优劣，不等同于实测干燥时间。
