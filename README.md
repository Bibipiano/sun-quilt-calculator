# sun-quilt-calculator

A locally run web tool to maximize quilt sunlight exposure（一个本地运行的网页：结合光照、重心、风速，计算如何让被子晒到最多，给出最优折叠方案）

[English](README_EN.md) | [中文](README.md)

> **在线体验**：https://bibipiano.github.io/sun-quilt-calculator/ （GitHub Pages 发布后生效）

> **一句话总结**：这是一个纯本地运行的网页工具。基于太阳轨迹与物理模型，帮你计算在特定纬度、季节、绳向和重力约束下，被子究竟怎么折叠、怎么搭，才能在一年 12 个月中每天获得最多的光照（受光面积 × 时间）。

## ✨ 核心功能

* **精确太阳轨迹**：内置 Spencer / NOAA 简化式，根据你所在位置（经纬度、海拔）和时间，精确计算日出日落、太阳高度角与方位角。
* **最优折叠算法**：自动寻优“长边搭绳”还是“宽边搭绳”，计算最佳折点比例（例如 66:34），以最大化露出被面的受光面积。
* **安全的物理约束**：结合卡普斯坦摩擦模型（Capstan friction）与离地高度限制，计算出最佳的悬挂比例，保证被子既晒得多，又不会滑落、不会拖地。
* **全景可视化**：
  * **3D 场景**：支持鼠标拖拽旋转，直观展示被子受光与背光面，时间游标可拖动。
  * **俯视方位图**：清晰标出绳向、法线、日出日落方位以及太阳当前所在位置。
  * **全年/单日图表**：直观对比全年 365 天的受光量变化，找出最佳晒被日。
* **纯本地计算**：无需后端，无外部依赖，所有数据计算与渲染均在浏览器端完成，保护隐私。

## 🚀 如何使用

### 方式一：直接本地运行（推荐）

1. 下载本仓库中的 `光照模拟器.html`（中文版）或 `Quilt Sun-Drying Simulator.html`（英文版）文件。
2. 双击该文件，使用任何现代浏览器（Chrome、Edge、Safari 等）打开即可直接使用；也可以在浏览器中打开 `index.html`，从入口页选择要使用的语言版本。

### 方式二：在线直接访问（GitHub Pages）

1. 进入你的 GitHub 仓库 `Settings` -> `Pages`。
2. 在 `Build and deployment` 下，`Branch` 选择 `main`，文件夹选 `/ (root)`，点击 `Save`。
3. 等待 1-2 分钟，刷新页面，你就能获得一个类似 `https://bibipiano.github.io/sun-quilt-calculator/` 的在线网址，点开即用。

### 操作指南

1. **填写位置**：输入纬度、经度、海拔（可留空），或点击“一键获取本机位置”。
2. **设置绳向**：用手机指南针沿晾衣绳方向读数并填入，或者在左侧罗盘上拖动圆点。
3. **设置被子参数**：输入你被子的长宽（如 2.0×1.5 米）、折叠厚度，以及晾衣绳的高度和长度。
4. **查看结论**：右侧首屏会自动给出“推荐晒法”，包括沿哪条边搭、折点比例，以及为什么这样推荐。

**想先看看效果？** 打开页面后，点击下图红框中的 **「填入演示示例（北京）」**，即可自动加载演示数据并直接给出推荐结果：

## 🛠️ 技术说明与模型局限

* **太阳位置**：Spencer / NOAA 简化式，包含大气折射与海拔地平下沉修正。
* **受光模型**：剪影 × 入射余弦（含两层被面互遮的近似），单位 m²·h。
* **摩擦与滑落**：基于质量均匀假设和卡普斯坦摩擦模型（接触弧 π），默认留 1.3× 安全余量。
* **能量估算**：基于大气质量（AM）与直射强度（DNI），考虑天气通透度 kc。
* **已知局限**：
  * 仅统计太阳直射光，未计入天空漫射光、地面反射、云层变化、风速和湿度（这些因素在阴天或低温下会影响实际干燥速度）。
  * 被子被理想化为“刚性平面悬挂”，忽略织物鼓包与层间贴合。
  * 无建筑、树木、阳台栏杆等遮挡模拟。
  * 结论适合**比较不同晒法、时段与季节的相对优劣**，不等同于实测干燥时间。
